# Gtask 1.0.1

这是一次发布链路补丁，不改变数据库结构和清单数据。

## 本次内容

- 软件更新默认先检查 Gitee 镜像，镜像不可用时自动回退 GitHub。
- 设置中可直接选择“自动（Gitee 优先）”、Gitee 镜像或 GitHub；选择后立即用于后续检查。
- 更新提示会根据实际命中的来源打开对应下载页。
- GitHub 继续保存权威提交、标签和发布说明；同一套安装包、便携包和 SHA-256 校验文件自动同步到 Gitee Release。
- 修正一项受真实日期影响的周期基准测试，避免发布验证在周期切换日产生误报；产品的周期滚动逻辑没有改变。

## 下载与说明

- 中国区网络可优先从 Gitee Releases 下载，也可随时使用 GitHub Releases。
- 项目不自建下载服务器，不使用付费对象存储或 CDN。
- 覆盖安装不会删除数据库、凭据或备份。
- 安装包暂未进行商业代码签名，Windows 可能显示未知发布者提示；请核对随版本提供的 `SHA256SUMS.txt`。
- Gtask 是非官方免费开源项目，不隶属于、未获得米哈游、HoYoverse、库洛游戏或相关权利方的认可与背书。
