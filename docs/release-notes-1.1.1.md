# Gtask 1.1.1

发布日期：2026-09-10

本次发布包含自 1.0.0 以来的界面、同步与清单更新。

## 界面与日常使用

- 调整总览、游戏导航和设置布局，统一开关、操作按钮和确认弹窗；小窗口保留紧凑导航。
- 事项与游戏版本剩余 3 至 7 天显示黄色提醒，进入最后 3 天显示红色提醒。
- 尚未开始的事项默认隐藏，可在设置中开启显示；到达开始时间后自动出现。
- 个人进度在后台同步，修复“只看未完成”时已隐藏版块短暂闪现的问题。

## 同步与清单修复

- 修复旧期个人战绩误勾选当前周期的问题，原神幻想真境剧诗优先匹配最新档期。
- 修复地图一级探索度在重启或更新清单后变化的问题；接口提供的一级值优先保留，缺失时再由二级地区计算。
- 修复周期换期时的重复卡片与空档计算，普通换期继续复用原有玩法卡片。
- 更新四款游戏截至 2026-09-05 已核验的公开清单差异；活动、周期与地图支持独立于软件版本更新。

## 维护与同步

- 个人进度接口在正常同步时会额外留下脱敏的官方档期观察；其中不含账号、完成状态、分数、探索度或登录信息。
- 本机 Codex 维护端会先比较这些第一方观察与公共基准，只对缺失或冲突字段补充公开检索。
- 全量维护任务会持久记录已完成与剩余版块，进入地图阶段后返回独立的地图契约、候选项和证据上下文。
- 维护契约升至 schema 15，继续坚持全版块核查、只写实际增删改、无变化不重写。

## 排期修正

- 鸣潮“终焉矩阵”改为按当前游戏版本相对计算：版本开始后的第七个日历日 04:00 开启，并在下次版本维护时结束。
- 鸣潮 3.6 当前版本结束时间校正为 2026-09-30 04:00（Asia/Shanghai）。
- 鸣潮个人周期接口中的未验证数值不再被误当成结束时间；周期窗口只由公共基准和已发布滚动规则负责，个人同步只回写可靠的完成状态。

## 数据安全

- 本地数据目录与历史名称自动迁移到 Gtask；出现新旧目录冲突时停止并提示，保留现有文件。
- 数据库 schema 升至 v5；迁移只新增维护任务阶段状态和脱敏档期观察表，不改变用户清单、完成状态、探索度、备份或登录信息。
- MCP 仍只归本机 Codex 管理端使用；普通用户只接收已经验证并发布的公共基准更新。
