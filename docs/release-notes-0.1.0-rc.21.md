# Gtask 0.1.0-rc.21

- 个人同步新增官方 ID 持久绑定、哈希账号隔离、个人状态、语义配置和脱敏观察审计。
- 四游戏周期挑战恢复机械快路径；原神、鸣潮地图首次建立映射后不再逐条消耗 Codex。
- 活动完成状态改为完成、未完成、未知三态；证据不足时保留用户当前状态。
- 已通过的历史 Codex 决策会自动回填来源绑定，被拒绝候选可在下次同步重试。
- Gtask MCP 增加协议版本握手；安装本候选版后需要在设置中更新一次 Gtask 插件。
- 保留公开任务、个人请求和语义审核的端到端取消，并增强 SQLite 迁移重入与并发容错。

验证：43 个测试文件、275 项自动测试通过，TypeScript 类型检查和生产构建通过。
