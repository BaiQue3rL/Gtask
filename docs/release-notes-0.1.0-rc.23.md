# Gtask 0.1.0-rc.23

- 地图探索目录精简为一级地区与具有独立探索度的独立地图，普通二级区域不再进入清单或个人同步队列。
- 已有公开地图目录时，个人区域名称与节点类型唯一一致即可建立官方 ID 绑定并机械写入探索度；绑定名称或类型冲突仍交给 Codex。
- 活动完成状态必须附带可从个人接口原始字段机械复现的语义规则；规则按来源绑定持久保存，后续相同官方 ID 直接走快路径。
- 排队中的任务只显示“排队中”，仅已领取任务显示处理进度；取消、重排和并行任务互不误伤。
- 移除等待接单五分钟后自动终止的旧逻辑，未领取任务会持续排队，应用重启后也可继续。
- 首次清单引导可以关闭；稀疏版块不再被强制压缩成过短的内部滚动区域。
- 数据库升级到 v23，MCP 协议升级到 `2026-07-28.3`。
