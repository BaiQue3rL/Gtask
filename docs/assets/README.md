# 软件快照说明

本目录中的图片均直接截取自 Gtask 软件界面，并使用隔离演示数据生成，不包含真实账号、凭据或用户数据库内容。

- `snapshot-overview.webp`：跨游戏任务与进度总览；
- `snapshot-custom-list.webp`：自定义清单面板；
- `snapshot-custom-editor.webp`：新增自定义事项窗口；
- `snapshot-filter-all.webp`：显示全部事项；
- `snapshot-filter-incomplete.webp`：只看未完成；
- `snapshot-settings-top.webp`：游戏显示和启动同步设置；
- `snapshot-settings-data.webp`：凭据、本地数据和备份设置。

图片不添加宣传口号、光效或软件中不存在的功能。更新 UI 后应重新生成并人工确认这些快照。
