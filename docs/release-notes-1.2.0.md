# Gtask 1.2.0

发布日期：2026-09-15

本版本按维护者明确要求于同日重新发布，版本号继续使用 1.2.0。重新下载本页安装版或便携版可获得以下地图修正；已经安装较早 1.2.0 的用户不会收到版本号变化提示。

## 本次地图修正

- 四个游戏共用新的一级分组逻辑，显示简洁的 `x/x` 子地图完成数；官方总探索度放在悬停说明中。
- 没有子地图的一级地区也统一显示 `0/1` 或 `1/1`，展开同名二级地区查看百分比及标记完成；共用原有进度，不产生重复地图。
- 未完成子区始终保留所属一级分组。全部已收录、已开放子区完成后才隐藏整组，避免官方总值与子区进度不一致造成误判。
- 新增子地图会重新显示分组，保留已完成子区；未知进度保持待确认。一级分组只负责展开和折叠，取消容易误改整组进度的勾选。
- 验证覆盖四游戏、两类父子进度矛盾、手动操作、未知进度、新地图加入、重启和窄窗口。

本次增加排期例外和公共清单维护能力，并集中改善同步准确性、数据恢复与大清单性能。应用继续读取统一清单，个人接口自动同步进度。

## 清单与同步

- 支持周期空窗、未来排期例外和规则生效边界，避免倒计时逐期偏移；同一期校时保留完成状态，实际换期保存历史后重置。
- 支持已确认开放、但尚未查到可靠截止时间的限时活动，显示“截止时间待确认”，不使用虚构日期。
- 完成状态区分明确完成、明确未完成与未知，减少旧期战绩、自动结算或缺失字段造成的误判。
- 保留个人接口提供的地区总探索度作为参考；修复沉玉谷特殊汇总项零值造成的完成状态回退。地图筛选始终保留未完成子区的所属分组。
- 账号退出或切换后丢弃旧请求结果，手动完成状态受到保护。

## 性能与可靠性

- 批量匹配与索引减少同步时的重复读取；大清单按视口渲染，保留键盘导航与可变行高。
- 设置和加密登录信息采用原子写入；公共清单更新与接收回执同事务保存，失败时保留已有数据。
- 增加快照保留上限、更新响应大小限制、并发请求合并与进程中断恢复验证。
- 修复小窗口版本倒计时隐藏的问题。

## 维护与兼容

- 公共清单支持 v1/v2，新增差异编译与统一校验入口；应用内置和远程更新消费同一份清单。
- 数据库升级至 schema 8，升级前自动备份，保留个人数据与登录信息。较旧版本不能直接打开升级后的数据库。
- 简化维护 Skill 和说明入口，历史设计文档保留为参考。

重新发布前完整测试 462 项通过、12 项跳过；类型检查、生产构建、清单校验、专项性能测试及隔离 Windows 打包界面验证通过。
