# Gtask 1.0.2

这是一次发布链路修复，不改变数据库结构、清单数据和 1.0.1 已有功能。

## 本次内容

- 修复 Gitee 在“标签尚无 Release”时返回空响应导致镜像发布中断的问题。
- Gitee Release 接口同时兼容数字与字符串资源 ID。
- GitHub Release 步骤支持安全重跑，发布中断后不会因为同标签 Release 已存在而再次失败。
- 软件更新仍默认使用“自动（Gitee 优先）”，也可在设置中固定选择 Gitee 镜像或 GitHub。

## 下载与说明

- 中国区网络可优先从 Gitee Releases 下载，也可随时使用 GitHub Releases。
- 项目不自建下载服务器，不使用付费对象存储或 CDN。
- 覆盖安装不会删除数据库、凭据或备份。
- 安装包暂未进行商业代码签名，Windows 可能显示未知发布者提示；请核对随版本提供的 `SHA256SUMS.txt`。
- Gtask 是非官方免费开源项目，不隶属于、未获得米哈游、HoYoverse、库洛游戏或相关权利方的认可与背书。
