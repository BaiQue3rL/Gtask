# Gtask 0.1.0-rc.14

## 重点变化

- 活动、周期和地图统一采用“Codex 决策、底层机械执行”，移除旧地图硬编码目录及个人周期数据直接写入路径。
- 地图支持主地区、子地区、独立地图和展示分组的可变层级；Codex 决定层级关系，数据库只校验引用与数值完整性。
- 独立地图有关联主地区时只在该一级目录下展示一次；一级目录主区域点击即可展开或收起，叶子节点点击仍进入编辑。
- 修复手动切换完成状态后整个工作区被重新挂载并跳回顶部的问题。
- 修复所有版块本地切换完成状态后未重新排序的问题；完成项在普通列表中全局沉底，在地图树中于同级目录沉底。
- 地图树按分组、主地区、独立地图、子地区稳定展示；同步规则不再创建仅用于包住全部地区的泛化世界根节点。
- 设置页的插件、登录和备份操作按钮统一尺寸、圆角、间距与右侧对齐。
- 左侧游戏入口使用本地内置的官方游戏图标，并统一主要控件和版块图标的视觉细节。
- 精简设置及插件说明文案，产品描述不再将未来可扩展范围限制为当前内置游戏。
- 数据库架构升级至 v17，新增地图节点类型、父节点和关联主地区稳定标识。

## 验证

- TypeScript、Vue 类型检查及全量自动化测试。
- 隔离数据目录执行全新数据库初始化、固定任务、首次同步状态和结构迁移测试。
- Windows 解包版与便携版启动、资源和 MCP 插件完整性验证。
