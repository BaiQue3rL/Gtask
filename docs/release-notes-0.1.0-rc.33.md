## 本轮重点

- 地图“同步清单”先即时恢复内置规范目录，不再无条件启动 Codex。
- 使用内置目录核验时间、最近一次成功的 Codex 地图任务和任务版块版本窗口共同判断目录是否可能过期。
- 进入新版本、跨过已知版本边界，或缺少可靠版本窗口且目录超过 30 天未核验时，自动排队一次 Codex 地图增量审计。
- 地图 Codex 任务把现有目录视为已核验基准，只提交新地区、官方改名或父级归属修正；没有变化时可直接确认完成，不重写整张地图。
- 普通本地目录合并时间与 Codex 联网核验时间分开记录，反复点击不会把旧目录伪装成已联网更新。
