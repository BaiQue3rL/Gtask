# Gtask 1.0.0

日期：2026-07-31

## 首个正式版本

- 提供原生 Windows 安装包、桌面快捷方式和开始菜单入口。
- 支持任务、限时活动、周期事项、地图探索和自定义清单。
- 支持公开资料同步、可用版块的官方个人进度同步，以及 Codex 增量核验。
- 地图采用内置两级规范目录，并按版本窗口触发新增地区、改名和父级归属核验。
- SQLite 数据、备份和加密凭据保存在用户系统目录，应用升级不会清除用户状态。
- 同步任务支持实时进度、排队、并发、取消和异常恢复。

## 发布验证

- 47 个测试文件、310 项自动化测试全部通过。
- TypeScript/Vue 类型检查和生产构建通过。
- 安装包 PE 结构、内置许可声明和 SHA-256 完整性检查通过。
- 静默安装后版本为 `1.0.0`，无界面 MCP 冒烟测试返回 17 个工具和 4 个游戏。
- 安装包 SHA-256：`4fb21941c80ec5e55c01579a65fd1a47ae659fdc36c2d44964bd9c94a2bf6946`。

当前本地正式构建未配置 Authenticode 代码签名证书。安装包内容完整可用，但面向陌生用户公开分发时 Windows 可能显示来源未知提示；发布者证书签名应作为后续 GitHub 公布前的发布工程项。
