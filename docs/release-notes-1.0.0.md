# Gtask 1.0.0

日期：2026-08-03

## 首个正式版本

- 提供原生 Windows 安装包、桌面快捷方式和开始菜单入口。
- 支持任务、限时活动、周期事项、地图探索和自定义清单。
- 支持彼此隔离的公开资料清单与官方个人清单；Codex 负责公开资料检索，个人接口完整快照由本地适配器原子写入。
- 地图采用内置两级规范目录，并按版本窗口触发新增地区、改名和父级归属核验。
- SQLite 数据、备份和加密凭据保存在用户系统目录，应用升级不会清除用户状态。
- 脱敏诊断日志保存在系统“文档”目录，记录运行环境、同步阶段与异常并自动轮换。
- 同步任务支持实时进度、排队、并发、取消和异常恢复。
- 版本校时通过独立游戏级版本窗口维护侧栏倒计时，优先采用官方精确维护时刻；公告尚未发布时可写入经交叉核验的可靠暂定时间，并在官方时间公布后自动校正。

- 58 个测试文件、355 项自动化测试全部通过，11 项环境相关测试按设计跳过。
- TypeScript/Vue 类型检查和生产构建通过。
- 安装包 PE 结构、内置许可声明和 SHA-256 完整性检查通过。
- 无界面 MCP 冒烟测试返回 16 个工具和 4 个游戏。
