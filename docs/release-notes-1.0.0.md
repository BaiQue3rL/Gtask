# Gtask 1.0.0

## 为什么做这个软件

玩的游戏多起来以后，我经常记不清每款游戏当前有哪些活动、周期任务和地图事项。进入游戏再逐层翻菜单，信息集中在不同页面里，内容一多容易看花，也容易漏掉原本想做的事情。Gtask 就是为了把这些待办整理到一个可以随时打开查看的本地清单里。

我是个人发布者，也完全不会编程。我负责提出实际使用需求、决定功能和交互取舍，并对每次修改进行人工验收；项目的代码、测试、构建脚本和技术文档均由 OpenAI Codex 根据这些需求实现。它是一个按个人需要逐步完善的免费开源工具，不提供商业服务或在线可用性承诺。

## 本次内容

- 新用户无需引导，启动后直接显示四游戏完整基准表和持续时间。
- 活动、周期挑战和地图使用持久公共基准；个人接口只同步完成/探索进度，不替换目录。
- 支持米游社与库街区应用内登录、版块手动同步及按游戏启动自动同步。
- 内置卡片改为紧凑只读布局，玩法标签与名称同行；自定义版块保留完整编辑能力。
- 周期挑战按本期手动挑战记录判断完成，排除自动继承、减负、扫荡和快速解锁。
- 星铁旧个人地图迁移到完整基准，保留进度并恢复一级/二级目录结构。
- 数据库升级到 v3，保留用户数据库、凭据、备份、完成状态和自定义事项。
- 后台 MCP 可热维护公共基准，但普通用户不需要安装或配置外部 AI 工具。
