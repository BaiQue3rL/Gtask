# Gtask 0.1.0-rc.30

日期：2026-07-31

## 本轮重点

- 地图目录统一为“一级主地区 / 二级地区”两层，移除其他节点语义和旧展示分组。
- 原神、绝区零、鸣潮使用经人工资料校对的内置地图目录；星铁建立当前公开目录，供试用阶段人工复核。
- 地图公开同步改为本地规范目录维护；个人地图按官方 ID 或规范目录内唯一正式名称建立持久绑定，后续机械写入探索度，只有冲突与缺项交给 Codex。
- 绝区零接入米游社官方区域收集接口，支持一级区域、二级区域与个人探索百分比。
- 地图界面恢复一级下拉二级、默认收起、双列展示、正文展开与菜单编辑。
- 用户关闭主窗口时取消全部同步、语义审核和登录请求，终止应用启动的 Codex 子进程并完整退出。
- 修正退出时遗留临时便携路径子进程、地图旧拒绝结果不可重试和个人地图秒完成但未写入等问题。

## 验证

- 自动化测试：46 个测试文件，297 项。
- TypeScript 与 Vue 类型检查通过。
- Electron/Vite 生产构建通过。
