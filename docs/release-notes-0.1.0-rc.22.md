# Gtask 0.1.0-rc.22

- “同步清单”和“同步进度”改为共享同一规范目录；用户可从空数据库直接先同步个人进度。
- 新增版块目录覆盖度：个人数据建立局部目录，公开资料确认完整目录，完整状态不会被后续个人增量降级。
- 个人来源身份首次由 Codex 建立绑定后，后续同步按稳定 ID 和已确认字段语义机械写入。
- 个人语义候选支持同游戏、同版块、同账号、同批次批量领取，显著降低地图首次建表的进程与 Token 开销。
- 公开资料后到时原位补全个人入口创建的规范项目，保留项目 ID、来源绑定、个人状态和手动完成锁。
- MCP 协议升级到 `2026-07-28.2`，内置插件同步升级。
- 数据库升级到 v21，并补充迁移重入、双入口顺序、批量领取和覆盖度回归测试。
