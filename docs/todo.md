# Gtask 后续工作

## 1.0 发布后验证

- 在全新 Windows 用户环境完成安装、卸载、桌面快捷方式和自定义安装目录验收。
- 分别验证米游社与库街区登录、人工验证和凭据清除。
- 用真实账号复核活动、周期事项和地图探索的首次个人快照及后续机械快路径。
- 验证公开数据与个人数据在同一版块互斥，失败或取消时保留上次成功快照。
- 验证超过六项同步任务时正确排队，单个 Worker 失败不影响其他任务。

## 长期维护

- 官方接口结构变化时只修改对应平台适配器及契约测试。
- 游戏版本新增地图时按 `docs/ai-map-catalog-maintenance.md` 维护两级基准目录。
- 新增周期模式时维护 `src/main/sync/cycle-catalog.ts` 并补齐周期边界测试。
- 发布新数据库结构时从 1.0 基线新增迁移，不恢复封闭测试期的历史迁移链。
