# Gtask 后续工作

## 1.0 人工验收

- 全新用户直接显示四游戏基准表，无首次引导或外部工具提示。
- 正式安装目录覆盖升级时保留数据库、凭据、备份、布局和手动完成状态。
- 验证米游社/库街区未登录弹窗、登录续跑、手动同步和启动自动同步。
- 用真实账号复核活动匹配、周期手动记录及地图探索百分比。
- 验证内置版块只读、自定义版块 CRUD 和回收站。
- 验证周期到期滚动、数据库备份轮换、应用退出及后台进程清理。

## 长期维护

- 每个游戏版本只核对并更新实际变化的活动、地图等公共事实；常规版更节奏未变时不重复更新版本窗口，深渊模式、规则和排期锚点未变时不更新周期清单。
- 只有官方延期、缩短、延长或其他常规周期无法表达的例外才校准版本窗口；只有官方增删改周期模式或改变排期规则/锚点才维护 `cycle-catalog.ts`。
- 新地图按 [ai-map-catalog-maintenance.md](./ai-map-catalog-maintenance.md) 更新稳定两级目录。
- 官方个人接口变化时只修改对应适配器与解析回归，不允许个人数据拥有目录结构。
- 新 schema 必须追加向前迁移并先创建迁移前备份。
