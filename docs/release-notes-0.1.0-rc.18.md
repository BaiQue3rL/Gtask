# Gtask 0.1.0-rc.18

- 同一游戏的活动、周期事项和地图同步任务改为独立排队与独立进度，不再互相覆盖。
- Codex 的 4 个工作槽只限制同时执行量；超出槽位的任务继续排队，不会取消已有任务。
- 公开资料任务唯一键由“游戏”调整为“游戏 + 版块”，同一游戏可批量提交多个版块。
- 个人语义审核进度按版块分别统计，界面可同时显示多个任务。
- 个人进度候选只返回当前版块的现有清单，减少跨版块干扰。
- 语义核验工具补齐 `archiveItems`，Codex 可在匹配规范清单的同时归档确认重复、错误或失效的同步项。
- 接口契约增强简称、字幕、节点名、来源 modeKey 粒度与服务器时区边界等同一事项识别语义。
