# 下次开发接续点

更新时间：2026-07-31（Asia/Shanghai）

## 当前架构

- 必须先读 [sync-architecture-redesign.md](./sync-architecture-redesign.md)。公开清单与官方个人清单已经隔离，旧的规范目录融合方案不得恢复。
- SQLite schema v27。个人同步成功时按游戏/版块创建完整快照并原子替换；部分响应、验证失败或取消均保留上次快照。
- 正常个人同步不创建公开资料任务或 Codex 语义任务；官方 ID、进度、挑战记录及地图父子结构由适配器机械写入。
- 公开资料 Codex 任务只读取和更新 `public_schedule`；个人快照只使用 `personal_sync`。
- 活动适配器会过滤已过期项目和已知周期挑战。无法证明玩家完成语义的官方活动状态不写 `completed`。
- 周常独立保留并每周一重置；主线、支线和自定义清单不参加数据源切换。

## 下一次人工验收

1. 使用测试版从空数据库启动，确认只有主线和支线。
2. 不同步公开清单，分别直接同步个人活动、周期和受支持地图，确认没有 Codex 排队且能直接建表。
3. 让同一版块再同步一次，确认项目 ID 稳定、进度更新、旧快照缺失项被移除且没有重复。
4. 人为触发凭据失效/部分接口失败，确认旧个人清单完全不变。
5. 再点击同版块“同步清单”，确认个人普通项被公开清单替换；自定义项、任务和周常保留。
6. 同时发起多个版块同步后取消或关闭应用，确认没有残留进程和取消后的写入。

## 仍需长期观察

- 各平台活动完成字段是否有可证明的玩家完成语义；没有证据前保持未知而不是猜测。
- 官方接口结构变更、账号切换以及空快照的真实行为。
- 便携测试版的杀毒拦截、临时解包和中文路径兼容；正式发布前再制作安装包。
