- 星铁活动完成误判已关闭并清理；活动“同步进度”只生成脱敏 Codex 核验候选，周期同步保留确定性直写。
- 全游戏未来活动完成、非地图百分比和 AI 活动时区已经增加统一数据库保护。
- 已实现并真实验收语义核验队列和 MCP 领取/通过/拒绝协议；三款米游社游戏活动候选均可脱敏入队，证据充分时回写、证据不足或分类错误时拒绝。
- 右上角刷新已改为直接按钮；排序已区分正在进行、尚未开始、已过期和已完成，避免把“距离开始”的小数字误当成高优先级。
- 绝区零真实活动同步更新 3 项、周期同步更新 2 项；原神真实活动同步更新 5 项并保护 1 项手动完成，三种周期接口均成功返回。
- 原神、星铁和绝区零现有适配器已统一为“本期只要存在有效挑战记录即完成，完全没碰才未完成”，并移除活动/周期解析百分比；2026-07-24 原神三项、星铁四项、绝区零两项已完成真实同步验收，鸣潮沿用相同语义。
- 活动轻量多玩法标签已实现：支持卡片显示、多标签筛选、用户编辑和 Codex 公开资料回写；资料不足时由 Codex 写入“待识别”，个人进度同步不会覆盖已有标签。
- 主线与支线版本倒计时、“版更校时”、版本切换/到期重置和任务版块独立同步时间已实现；卡片仅显示统一的“剩余 ××”短文案。数据库已升级到 v15，Codex 插件协议与缓存版本 `0.1.0+codex.20260724134654` 已同步。
- 全部版块的结束倒计时严格小于 72 小时时显示红色；“距离开始”不使用该红色预警。该逻辑已实现，尚待真实窗口视觉验收。
- 右上角已明确显示“全局清单 · 已同步/未同步”，只记录全局清单；顶部旧的任意同步时间已移除，活动、周期、地图继续各自显示版块时间。
- 语义核验队列已在桌面端显示当前游戏待处理/处理中数量、最近结论和“打开 Codex 处理”入口，并每 4 秒更新。
- 原神、星铁、绝区零的活动个人状态已统一改为脱敏后进入 Codex 核验；本地不再根据活动日历标题、状态枚举、完成数字或无时区文本直接写分类、时间和完成状态。
