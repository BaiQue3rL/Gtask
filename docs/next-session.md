- 自动同步及启动联网已移除。

1. 打开真实窗口检查新增状态标识、时间戳和菜单宽度。
2. 原神依次手动测试活动、周期、地图“同步进度”，一次只测一个版块；记录验证后 1034 出现在同一接口还是下一个接口。
3. 确认周期多个接口部分失败时，已成功模式仍写入且旧数据不丢失。
4. 星铁只回归周期；绝区零回归活动与周期。
5. 上述通过后重新构建便携包。
