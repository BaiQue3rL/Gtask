# 下一次开发接续点

更新时间：2026-08-09（Asia/Shanghai）

## 当前基线

- 产品版本：Gtask 1.0.0；数据库 schema 为 v3，支持 v1 → v2 → v3 安全迁移。
- 活动、周期、地图和版本时间由内置持久基准表提供；个人接口只更新唯一匹配行的完成/探索进度。
- 不再存在公开/个人目录切换、用户公开数据同步、首次引导、个人语义复核或个人元数据补标。
- 支持版块提供“同步进度”；未登录时弹窗直接进入米游社/库街区登录。
- 设置页可按游戏开关启动自动同步；自动同步时间戳在本地隐藏保存，10 分钟内重复启动不会再次同步，手动同步不受冷却限制。
- 内置卡片没有新增/编辑/删除入口，标签与标题同行；自定义版块保持完整 CRUD。
- 后台 MCP 只维护公共基准表，不是产品使用前置条件。
- 地图严格为 `region/subregion` 两级；维护前完整阅读 [ai-map-catalog-maintenance.md](./ai-map-catalog-maintenance.md)。

## 本轮关键修复

- 星铁旧个人目录迁移时先种完整基准，再吸收完成/探索进度，避免残缺一级目录和二级下拉丢失。
- 周期挑战按“存在本期必须手动挑战记录即完成”判断；自动继承、减负、扫荡和快速解锁不算记录。
- 鸣潮冥歌海墟不再要求整期窗口已绑定才承认官方手动挑战记录。
- 基准表只覆盖更旧数据，保护 MCP 热维护得到的新内容不被发布包倒退。
- schema v3 删除旧个人复核/元数据缓存链路，并把内置版块的手动事项迁入自定义。
- 原神个人地图即使把基准二级地区返回为独立 region，也会按游戏内唯一名称绑定并保留基准层级；完成状态已通过关闭、重开数据库回归。
- “只看未完成”会隐藏已完成地图父项，并把仍未完成的子地区临时提升显示；探索度 100% 视为完成。
- 同步过程卡、结果通知和取消入口已经移除；后台同步只更新版块状态与数据，不弹同步消息。
- 版块同步标记只对确有个人适配器的目标显示；原神和星铁活动仅采信官方接口明确的“全部完成”布尔字段，不再丢弃该确定状态。
- 四款游戏的版本、活动、周期和地图基准已于 2026-08-09 重新核查；内置活动强制具有时间与玩法标签，所有周期模式强制具有当期起止时间。
- 修正原神“虚海望”名称并保留旧稳定键；补齐绝区零莱姆尼安空洞与厄匹斯港地图目录。
- 修复旧周期占位记录从“等待官方时间”升级为确定窗口时的稳定键唯一约束冲突：过期周期先换期，同一 `remoteKey` 的窗口校准原位更新并保留当前期完成状态。

## 后续人工验收

1. 四款游戏首次打开都能直接看到活动、周期、地图和版本倒计时。
2. 星铁地图一级目录、二级下拉及公开清单重启后保持完整。
3. 对支持版块分别测试未登录弹窗、登录续跑、手动同步和启动自动同步。
   - 额外确认 10 分钟内反复关闭/启动不会再次自动同步，手动点击仍可立即同步。
4. 对四游戏周期分别验证零记录、自动减负记录、部分手动挑战和明确战绩。
5. 确认内置卡片不能编辑/删除，自定义版块仍可新增、编辑、归档和恢复。
6. 确认真实数据库、凭据和备份沿用，关闭应用后无 Gtask/MCP/Worker 残留进程。
7. 检查四款游戏所有活动都有倒计时和玩法标签、所有周期卡片都有起止时间。
