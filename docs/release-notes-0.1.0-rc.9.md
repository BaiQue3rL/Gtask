# Gtask 0.1.0-rc.9

## 本轮修复

- 新用户 Codex 安装改用自动发现的 `personal` marketplace，修复“市场存在但找不到插件”。
- 正式包内置插件与 MCP，但不静默安装；应用内提供三步安装、重新检测引导。
- MCP 改用稳定启动器。目录版、便携版重新解包或后续安装版路径变化时，应用启动后会刷新真实路径。
- Codex 连接真实重试时提供三级处理：用户手动切换全局/TUN、自动注入系统代理的本地端口、仍失败时切换 HTTPS/SSE 兼容连接。
- 自动修复仅作用于 Gtask 启动的 Codex Worker，不永久修改用户的 Codex 配置或 Windows 网络设置；重启任务前明确提示额外 Token 消耗。
- 修复 Worker 注入代理环境后丢失父进程 `PATH/LOCALAPPDATA`，导致便携版无法发现 Codex Desktop CLI 的问题。
- 全局同步改为四版块累计完整性门槛：部分结果可先安全保存，但缺少任务、活动、周期或地图时任务继续检索，不能提前显示完成。
- Codex 恢复原生自主联网检索，不再受固定搜索次数、固定来源路线或更短软超时约束；MCP 只校验结果完整性与安全边界。
- 四款游戏在全局/周期同步开始时由本地机械建立固定周常，不再依赖 Codex 是否找到挑战排期。
- 修复四版块齐全后仍未更新全局 `all` 成功状态，导致右上角时间戳长期停留在部分同步的问题。
- 已安装插件的设置页增加“检查插件更新”，应用升级插件规则后仍由用户在 Codex 中确认更新，不静默改变权限。
