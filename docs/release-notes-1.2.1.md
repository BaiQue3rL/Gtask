# Gtask 1.2.1

发布日期：2026-10-14

本版本修复自动同步中的完成判定，并保留现有清单、个人进度、设置和登录信息。

## 完成判定

- 修复绝区零活动已在游戏内完成、自动同步却仍未勾选的问题，包括“「弹球勇者」哐哐当！”；同一接口的新活动自动采用相同判定规则。
- 各游戏采用官方接口各自的完成含义，避免把生命周期状态、奖励数量或剩余次数误当作完成进度。
- 接口缺失或无法解释的完成信息保留原状态与可靠证据；手动完成状态继续受到保护。
- 残缺活动列表、重复标识或冲突的完成证据不会覆盖上次有效结果。

## 同步与维护

- 同步成功统一显示“已同步”和同步时间，完成判定由独立链路处理。
- 保留已完成的维护提速、官方更正优先级与公共基准修复；公共清单负责目录和排期，个人同步只更新匹配项目的进度。
- 数据库保持 schema 8，升级沿用原有数据、设置与凭据。

## 下载

- `Gtask-1.2.1-setup.exe`：Windows 安装版。
- `Gtask-1.2.1-portable.exe`：Windows 便携版。
- `SHA256SUMS.txt`：两种程序的 SHA-256 校验值。

已有 1.2.0 用户可在新版本正式发布后通过软件更新入口获取本次修复。
