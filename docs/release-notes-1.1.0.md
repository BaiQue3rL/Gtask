# Gtask 1.1.0

## 新功能

- 尚未开始的公共基准事项默认不在总览中显示，到达开始时间后自动出现。
- 设置新增“显示尚未开始的基准事项”开关，需要提前规划时可以恢复完整时间表。

## 名称与数据迁移

- 源码、窗口 API、后台 Agent、MCP 工具、资源 URI 和 Codex 插件统一使用 Gtask 命名。
- 本地数据迁移到 `文档\Gtask`，正式数据库改为 `data\gtask.sqlite`，备份统一使用 `gtask-` 前缀。
- 启动前自动迁移已发布版本的数据目录、SQLite WAL/SHM 和备份名称；遇到新旧目录冲突时停止并提示，不猜测或覆盖数据。
- 数据库 schema 升至 v4，历史后台 Agent 关系原位迁移到新的稳定标识。
- Windows AppID 更新为 `com.gtask.app`，同时固定既有 NSIS 安装 GUID，保持覆盖升级和卸载身份连续。

## 兼容性

- 自定义事项、个人同步事项、没有有效开始时间的基准事项不会被隐藏。
- 游戏显示偏好从旧存储键一次性迁移，用户设置不会因名称调整丢失。
- 普通用户不需要安装 Codex 插件；插件仍只用于本机 Codex 管理端维护公共基准。
