## 本机性能结果

目标在测量前确定：正常启动 p95 ≤ 3 秒；列表/完成操作 p95 ≤ 100 ms；500 张地图 + 5,000 条自定义事项夹具的个人同步 p95 ≤ 150 ms；空闲不重建整张列表。

| 同一负载或场景 | 优化前 | 最后验证 |
| --- | --- | --- |
| 500 张地图 + 5,000 条自定义事项，首次建立个人匹配 | 19,341 ms | 31.8 ms，专项断言 < 150 ms 通过 |
| 相同夹具后续同步 | p95 约 64 ms | p95 约 17 ms，专项断言 < 150 ms 通过 |
| 可见清单修订查询 | p95 约 12.8 ms | 约 0.1 ms，专项断言 < 5 ms 通过 |
| 20 次独立新数据目录启动至可交互 | 未记录同规模启动分布 | p95 477.8 ms；最大 533.4 ms |
| 正常清单 IPC 读取，20 次 | 约 1～3 ms | 最大 1.8 ms |
| 5,000 条自定义清单 IPC 读取，20 次 | 最大约 135 ms | 最大 63.0 ms |
| 5,000 条自定义清单完成交互，10 次 | 原动画路径首个操作卡住；移除批量动画后 258～476 ms | 47.6～63.9 ms，包含实际写入与下一帧显示 |
| 大清单重载到可见 | 约 631 ms | 132.4 ms |
| 大清单 DOM 中的事项行 | 5,014 | 41；完整内容仍可滚动访问 |
| 渲染进程工作集 | 中间改进版约 1.5 GB | 含多行编辑、重载后约 300 MB |
| 大清单空闲 5.2 秒长任务 | 旧路径存在反复大渲染风险 | 0；最后一次记录的长任务列表也为空 |

这些是本机隔离环境、合成大数据和小样本交互测量，不是对所有硬件或未来官方接口的保证。10 次交互与 20 次读取在报告中使用最大值，作为保守边界，不混淆为大样本统计。首次同步数值取各阶段真实 JSON，性能脚本保留原始样本。
