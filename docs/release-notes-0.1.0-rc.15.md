# Gtask 0.1.0-rc.15

## 重点变化

- 正式软件名称更新为 Gtask，并统一窗口、软件内品牌、程序包、快捷方式和插件展示名称。
- 重绘 Gtask 矢量图标；程序图标保留深色底与留白，软件内使用透明中央标志和非衬线品牌字体。
- 公开资料与个人进度领取接口新增机器可读版块契约；Codex 先读取检索范围、字段语义和完成条件，再自主联网查全并回写。
- 精简同步技能中的版块字段提示，以接口契约作为唯一数据要求来源；提示词仅保留联网核验、语义匹配、进度和安全流程。
- 限时活动机械要求完整起止时间与玩法标签，开始后倒计时自动由“距离开始”切换为“剩余”；常驻活动禁止错误结束时间。
- 周期挑战机械要求模式身份、周期身份和完整起止时间；地图目录机械要求节点类型及二级节点父级。
- 补齐专用事项更新接口的活动标签、地图节点类型、父级和关联地区字段。
- 常驻活动与限时活动统一参与旧玩法标签标准化和后续补全。
- “社区尚未登录”提示增加直达对应登录卡片的跳转按钮，并修正库街区手机登录按钮文案溢出。

## 验证

- TypeScript、Vue 类型检查及全量自动化测试。
- MCP 公开资料契约、个人进度契约和专用事项更新字段验证。
- Windows 便携版资源、图标和内置 Codex 插件完整性验证。
