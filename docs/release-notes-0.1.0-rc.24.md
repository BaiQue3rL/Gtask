# Gtask 0.1.0-rc.24

- 个人同步改为“规范清单优先”：活动、周期事项或地图目录为空/不完整时，点击“同步进度”会自动先创建对应版块的公开资料任务。
- 个人接口数据在规范清单完成前只作为脱敏观测暂存，不能被 Codex 领取，也不能直接创建或修改清单；目录完成后再建立官方 ID 绑定并合并进度。
- 已由 Codex 确认的来源 ID 绑定继续走机械快路径；个人接口的名称或层级提示发生差异时，不再推翻 Codex 已确认的规范映射。
- 个人同步进度会区分“正在先建立规范清单”和“Codex 正在核验”；公开资料任务失败后允许用户重新同步，不把暂存观测误报为成功。
- 初始化提示中的“同步公开资料”按钮右移，与关闭按钮形成紧凑的右侧操作区。
- MCP 协议升级到 `2026-07-29.1`，个人语义审核契约升级到 v5。
