# 阶段验收清单

适用版本：Gtask 1.0.0 基准表重构测试版（2026-08-09）

## 自动检查

- TypeScript/Vue 类型检查、全量 Vitest 和生产构建必须通过。
- v2 → v3 迁移必须证明完整基准先建立、旧个人进度被吸收、内置手动项迁入自定义。
- 周期测试覆盖零记录、自动减负、部分手动挑战和明确战绩。
- 地图测试覆盖四游戏、稳定键、两级父子结构和基准新鲜度。
- 产品文案测试禁止在渲染层出现外部 AI、公开数据同步、来源切换或首次引导。

## 手动验收

1. 首次启动直接看到四游戏活动、周期、地图与版本时间。
2. 星铁地图一级目录完整，展开后二级目录存在；重启后不变成“同步中”。
3. 内置卡片无新增、编辑、删除菜单；玩法标签与名称同行，卡片高度明显缩短。
4. 自定义版块可新增、编辑、完成、删除、批量归档和回收站恢复。
5. 支持个人数据的版块显示“同步进度”；无凭据时弹窗直接提供米游社/库街区登录。
6. 登录成功后当前同步自动续跑，不跳转设置页。
7. 设置页可逐游戏开关启动自动同步；重启后只同步开启且已登录的游戏一次。
8. 个人同步不新增目录、不改变标题/标签/时间/地图层级，只改变可靠完成状态和探索度。
9. 周期完成按本期手动挑战记录判断，自动继承或减负结算不算完成。
10. 创建手动备份、恢复测试备份并确认恢复前安全副本；数据目录和凭据目录保持独立。
11. 关闭应用后确认无 Gtask、MCP Node 或后台维护 Worker 残留。

## 数据安全预期

- 安装或覆盖程序目录不删除数据库、凭据、备份和日志。
- 恢复前创建安全副本；损坏或未来 schema 数据库在替换前拒绝。
- 每日备份最多 30 份，其他备份不自动删除。
- 启动自动同步无凭据时静默跳过，不反复弹登录框。
