# Gtask 0.1.0-rc.5

这是面向数日真实使用的 Windows 单文件便携候选版。

## 本版重点

- 完成原神、星铁、绝区零、鸣潮四游戏清单与个人进度链路验收。
- 兼容库街区新版 BAT 和 JSON 字符串响应，修复登录后立即提示令牌失效。
- 鸣潮逆境深塔、冥歌海墟、终焉矩阵统一稳定模式键，个人进度与公开排期原位合并，不再重复或显示异常超长倒计时。
- 鸣潮地图探索真实同步成功，公开目录与个人百分比安全合并。
- 活动标签强制补全，无“待识别”；旧活动也会进入 Codex 核验。
- 修正设置页备份按钮列的间距与对齐。

## 验证结果

- 35 个测试文件、214 项自动化测试通过。
- TypeScript 与 Vue 类型检查通过。
- 当前真实数据库健康审计通过：无自动清单重复、无活动空/未知标签、无错误时间窗口、无非地图百分比、无未来活动误完成。
- 打包前已创建手动安全备份，用户现有清单与登录凭据未清空。

安装版、签名、自动更新与 GitHub 正式发布将在本候选版完成数日真实试用后进行。
