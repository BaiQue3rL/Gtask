# 同步适配器边界

## 公开数据

公开数据由 Codex 通过 MCP 领取 `public_catalog` 任务并联网检索。接口契约声明当前版块需要的字段、输出语言和用户时区；Codex 负责名称、分类、时间、标签及来源语义，应用只校验结构并以事务写入 `public_schedule` 清单。

公开数据不包含账号完成状态或探索度。任务失败、取消或资料不足时保留上次成功清单。公开数据与个人数据不会自动融合，用户主动切换来源时才原子替换目标版块。

## 个人数据

每个平台适配器只访问自己的官方接口：原神、崩坏：星穹铁道和绝区零使用米游社，鸣潮使用库街区。登录凭据由主进程本地加密保存，不进入渲染进程、Codex 请求或日志。

适配器输出完整的官方个人快照并负责确定性字段转换。稳定官方 ID、明确进度和已验证完成规则走机械快路径；分类、生命周期、层级或字段语义异常进入 `personal_review` 批次；活动标签和缺失时间由 `personal_metadata` 后台补全。异常任务不能阻塞已经安全建立的快照。

个人同步只有完整成功后才激活新快照。部分响应、验证失败、取消或 Codex 复审失败均保留上次成功数据。

## 传输与风控

个人接口使用 Electron/Chromium 网络栈并跟随 Windows 网络环境。官方要求滑块、短信或会话验证时由独立受限窗口交给用户完成；应用不绕过验证，也不共享第三方机器人凭据池。

全局个人同步按版块串行请求并保留请求间隔，避免同一账号瞬间并发触发风控。不同游戏和 Codex 后台任务由统一队列控制并发和取消。
