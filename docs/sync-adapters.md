# 同步适配器边界

## 公共基准维护

后台维护任务通过本地 stdio MCP 领取 `public_catalog`，联网核验活动、周期、地图或版本窗口，并提交结构化结果。应用只校验类型、稳定身份、两级地图、时间窗、来源证据和事务边界。该流程不在普通用户界面出现，不读取凭据或个人数据，也不提交完成状态和探索度。

## 个人进度

原神、崩坏：星穹铁道和绝区零使用米游社；鸣潮使用库街区。凭据由主进程通过 Windows DPAPI 加密保存，不进入渲染进程、维护任务或日志。

适配器只访问对应官方接口，输出：

- 稳定官方身份；
- 可验证的活动匹配信息；
- 本期手动挑战记录；
- 地图探索百分比；
- 完整性、适配器版本和脱敏账号作用域。

协调器按目标版块过滤和规范化数据。数据库仅把进度写到唯一匹配的公共基准行；个人输出不能新增、改名、归类、重设时间、增加标签或改变地图父级。无法匹配的记录计为保护项并忽略。

只有目标接口完整成功才提交事务。部分响应、限流、人工验证、凭据失效、取消和解析失败都保留上次数据。相同平台请求保持串行，避免瞬时并发触发风控。

## 周期完成证据

周期模式只有在官方响应中存在本期必须手动完成目标的可靠记录时才算完成；玩家不需要满星、满分、最高层或清空全部奖励。完成证据必须来自适配器已验证的布尔标记、正数战绩或战斗明细。自动继承、减负结算、扫荡、快速解锁、汇总星数、预生成关卡/阵容结构都不是证据。
