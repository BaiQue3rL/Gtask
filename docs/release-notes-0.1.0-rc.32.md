# Gtask 0.1.0-rc.32

日期：2026-07-31

## 本轮重点

- 个人同步新增“官方事实”契约：登录后的官方接口已明确给出的稳定 ID、本地化名称、时间窗、探索度、父子结构及挑战记录不再由 Codex 重复联网证明。
- 地图基准表缺少节点时，只有官方 ID、中文名称、0–100 探索度和明确父子结构同时成立才机械增量补入；ID 冲突、父级缺失或结构矛盾仍进入 Codex。
- 周期事项优先按模式、当期时间窗和周期身份机械绑定；完整官方字段可直接补入缺失的当期项目，历史期数不会再被稳定模式键误更新。
- 活动只机械绑定确定的官方身份与时间，完成字段语义仍需首次核验并保存可复用规则，避免重新引入误完成。
- 已过期活动和周期候选在进入绑定/审核前过滤；Codex 语义候选改为每批 6 条，让两个后台 Worker 实际分担队列。
- Codex 只核验剩余的身份冲突、分类或完成语义；少量交叉核验仍不明确时保留原状态，不再为单条个人候选无限检索。
- 最后一条语义候选处理完成后同步状态与时间戳会自动结算，不再长期停留在“正在核验”。

- TypeScript 与 Vue 类型检查通过。
- 插件技能与清单验证通过。
