# Gtask 0.1.0-rc.13

## 重点变化

- 四款游戏的数据同步统一改为 Codex 负责语义决策，底层工具按明确 ID 和稳定远端键机械执行。
- Codex 可新增、修改、匹配，并将确认错误、重复或失效的同步项移入回收站；手动事项和固定任务保持保护。
- 去除数据库中的硬编码挑战目录完整性否决，避免当前玩法变化时与 Codex 的核验结果冲突。
- 活动版块新增“全部活动 / 限时活动 / 常驻活动”筛选，原神、星铁、绝区零、鸣潮同时生效。
- 修复星铁个人活动完成状态在数据库启动时被旧安全逻辑清空的问题。
- 公开资料与个人数据均使用 Codex 明确指定的匹配项原位合并，减少异源名称差异导致的重复清单。

## 验证

- TypeScript 与 Vue 类型检查通过。
- 228 项自动化测试通过，覆盖四游戏 Codex 可恢复删除、手动项保护、严格匹配和同步状态。
