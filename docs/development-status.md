# Gtask 1.1 开发状态

## 已完成

- Windows Electron + Vue 3 + TypeScript + SQLite 桌面应用。
- 原神、星铁、绝区零和鸣潮的活动、周期挑战、地图探索和自定义清单。
- 无引导的基准表首屏、游戏版本倒计时和紧凑只读内置卡片。
- 米游社/库街区应用内登录、版块手动同步和按游戏启动自动同步。
- 个人进度只覆盖基准行，不替换目录；完整响应、稳定身份绑定、失败保护和事务写入。
- 周期手动挑战证据规则、周期到期滚动和两级地图目录。
- 自定义清单 CRUD、回收站、完成状态、筛选和版块拖动布局。
- DPAPI 凭据、每日/迁移前/恢复前/手动备份、安全恢复和日志轮换。
- 后台 MCP 基准维护、结构化契约、受保护写入和协议版本校验。
- 软件更新检查、NSIS 安装器、解包目录、便携包和构建验证。
- 历史产品命名迁移到 Gtask，包含数据目录、数据库、备份、MCP、插件和 Windows 应用身份。
- 尚未开始的公共基准事项默认隐藏，设置中可选择提前显示，到点后自动出现。
- 视觉体系已按 Fluent 2 暗色语义令牌和 Primer 列表/交互原则重构：午夜蓝表面、品牌紫与信息蓝分工、状态语义色、分组事项列表、分类设置页、窄窗口紧凑导航和统一侧栏页脚；约束见 [design-system.md](./design-system.md)。

## 发布边界

- 当前产品版本为 1.1.0；数据库 schema 为 v4。
- 正式包不包含测试数据库、登录凭据、开发缓存或临时研究资料。
- 普通用户不需要安装或配置外部 AI 工具。
- 后台维护接口不在 UI 中展示，不能读取凭据或覆盖用户完成状态。

后续验收见 [todo.md](./todo.md)，架构边界见 [sync-architecture-redesign.md](./sync-architecture-redesign.md)。
