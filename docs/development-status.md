## 已完成

- Electron + Vue 3 + TypeScript + SQLite 工程骨架、Windows 单实例窗口和品牌图标。
- 固定支持原神、崩坏：星穹铁道、绝区零、鸣潮；主线/支线只记录完成状态。
- 手动事项新增、编辑、完成切换、软删除、按游戏回收站及单条恢复。
- 任务、活动、周期事项、地图探索、自定义清单均有只作用于当前版块的“删除已完成”。
- 设置页可隐藏不玩的游戏，仅影响左侧入口且至少保留一款可见，原清单数据不受影响。
- 清单行使用“完整标题与倒计时 + 类型/来源/重置规则”两层布局；内部模式键不展示，逐条同步时间仅保留在悬浮说明，避免挤占正文。
- 总览四个版块改为左右两列独立纵向流；任务卡按两行内容自然收缩，周期事项紧随其后，不再为右侧活动卡等高留白。
- 限时活动起止时间和实时倒计时。
- 新用户每款游戏只预置不可删除的主线/支线状态，活动、周期和地图保持空白，并显示首次全局同步引导；同步任务携带用户系统时区。
- 首次同步建立“周常”后将其转为不可删除的长期状态项；周常统一每周一按官方服务器时区自动重置，完成后立即沉到版块末尾，下周重置后回到未完成队列。
- 活动、周期事项、地图探索均有独立同步菜单；任务版块固定为主线/支线，不显示同步、清理已完成或新增入口。
- 版块同步任务在 Agent 检索、个人适配器过滤和数据库回写三层限制目标类别，禁止跨版块写入。
- 四款游戏内置 22 个经公开来源核对的大区域基础目录（原神 7、星铁 6、绝区零 3、鸣潮 6）；首次新增为 0%，后续公开同步只增量新增/更新元数据且不覆盖进度；个人数据可按稳定区域键补齐探索度与完成状态。
- 未完成事项按临期优先排序，进入结束前最后 24 小时的周常、活动或其他周期事项置于所属版块最前；已完成事项统一沉底。
- 只有周常按上海服务器时间在每周一自动重置。深渊/挑战不再本地自动滚动；公开资料用稳定模式键和每期独立的周期键/远端键新增记录，已完成旧期保持完成。
- AI/MCP 公开资料写入只接受带 `Z` 或明确 UTC 偏移量的时间；任务同时携带用户系统时区，海外来源需先确认服务器时区和夏令时，再保存绝对时刻。
- 活动、周期和地图版块支持导入官方资料图片：中文 OCR 完全在本机运行，图片不上传也不持久化；用户可选择来源 UTC 偏移、逐项校对中文名称和本地时间，确认后再走与公开资料相同的安全合并通道。
- 图片导入周期玩法可补充稳定玩法标识；无法可靠识别的行允许在 OCR 原文旁手动补录，不做无确认自动写入。
- 深渊/挑战模式保存模式标识、周期键和起止时间；进入新周期时新增独立事项，不改写旧期完成状态。
- 四款游戏的周期同步均校验主要挑战完整性：原神三种、星铁四种、绝区零两种、鸣潮两种；缺任一项整批回滚。完成过初始同步但缺少固定周常的旧数据会在启动时自动补齐。
- 新增周期事项默认分类为深渊/挑战；新增事项的标题、地图区域、模式键和重置说明示例按当前游戏分别显示。
- 地图探索上级区域和 0～100% 探索进度。
- 每游戏独立的手动/自动模式；立即执行菜单统一为“同步清单 / 同步进度 / 同步本地”，自动范围显示为“同步清单”或“清单和进度”。
- 启动自动同步协调器、同游戏防重复请求、来源级成功/失败/需要验证状态。
- 事务化远端合并：不删除手动项目、不恢复已归档项目、不覆盖本周期手动完成锁、批次失败整批回滚。
- 公共排期和个人数据按规范远端标识合并；适配器数据有运行时校验。
- 上次成功时间、失败/过期/需要验证状态持久化；成功数据超过 24 小时标记过期但不删除。
- Electron `safeStorage`/Windows DPAPI 凭据保险箱底座，以及设置页状态和一键清除入口。
- 每日 SQLite 在线一致性备份、升级前强制备份、设置页立即手动备份和全部备份列表；自动每日备份保留最近 30 份，手动及安全备份不自动清理。
- 安全备份恢复：数据库身份与完整性校验、恢复前安全副本、失败回滚、Windows 原生确认和恢复后重启。
- 桌面端、CLI 和 MCP 均在数据库升级前强制创建旧版本一致性备份；v6 保存同步来源 URL。
- 本地 JSON 命令服务、CLI 和 stdio MCP server；提供清单读写、恢复、版块清理和备份元数据资源。
- 批量事务写入、中文无损输入，外部进程写入后桌面端约 2 秒内自动刷新。
- 公开资料文档契约、安全 HTTP loader，以及跟随 Windows 系统代理的 Electron/Chromium 传输适配层。
