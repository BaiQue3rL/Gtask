# 开发状态

更新时间：2026-07-22 19:15（Asia/Shanghai）

## 已完成

- Electron + Vue 3 + TypeScript + SQLite 工程骨架、Windows 单实例窗口和品牌图标。
- 固定支持原神、崩坏：星穹铁道、绝区零、鸣潮；主线/支线只记录完成状态。
- 手动事项新增、编辑、完成切换、软删除、按游戏回收站及单条恢复。
- 任务、活动、周期事项、地图探索、自定义清单均有只作用于当前版块的“删除已完成”。
- 设置页可隐藏不玩的游戏，仅影响左侧入口且至少保留一款可见，原清单数据不受影响。
- 清单行使用“完整标题与倒计时 + 类型/来源/重置规则”两层布局；内部模式键不展示，逐条同步时间仅保留在悬浮说明，避免挤占正文。
- 总览四个版块改为左右两列独立纵向流；任务卡按两行内容自然收缩，周期事项紧随其后，不再为右侧活动卡等高留白。
- 限时活动起止时间和实时倒计时。
- 四款游戏固定保留“周常”状态项；周常统一每周一按 Asia/Shanghai 自动重置，完成后立即沉到版块末尾，下周重置后回到未完成队列。
- 未完成事项按临期优先排序，进入结束前最后 24 小时的周常、活动或其他周期事项置于所属版块最前；已完成事项统一沉底。
- 深渊/挑战模式的模式标识、周期键、起止时间；进入新周期时清除上一周期完成状态。
- 地图探索上级区域和 0～100% 探索进度。
- 每游戏独立的手动/自动模式，以及“公开排期”或“公开排期 + 米游社/库街区”同步范围。
- 启动自动同步协调器、同游戏防重复请求、来源级成功/失败/需要验证状态。
- 事务化远端合并：不删除手动项目、不恢复已归档项目、不覆盖本周期手动完成锁、批次失败整批回滚。
- 公共排期和个人数据按规范远端标识合并；适配器数据有运行时校验。
- 上次成功时间、失败/过期/需要验证状态持久化；成功数据超过 24 小时标记过期但不删除。
- Electron `safeStorage`/Windows DPAPI 凭据保险箱底座，以及设置页状态和一键清除入口。
- 每日 SQLite 在线一致性备份、升级前强制备份、设置页立即手动备份和全部备份列表；自动每日备份保留最近 30 份，手动及安全备份不自动清理。
- 安全备份恢复：数据库身份与完整性校验、恢复前安全副本、失败回滚、Windows 原生确认和恢复后重启。
- 桌面端、CLI 和 MCP 均在数据库升级前强制创建旧版本一致性备份；v6 保存同步来源 URL。
- 本地 JSON 命令服务、CLI 和 stdio MCP server；提供清单读写、恢复、版块清理和备份元数据资源。
- 批量事务写入、中文无损输入，外部进程写入后桌面端约 2 秒内自动刷新。
- 公开排期文档契约、安全 HTTP loader，以及跟随 Windows 系统代理的 Electron/Chromium 传输适配层。
- AI 排期 Agent 五分钟心跳、刷新任务队列、任务领取/失败状态和专用 MCP 批量回写；已连接 Agent 或已安装 Codex 插件时刷新可用。
- 公开排期仅能回写限时活动、周常和深渊/挑战；常驻活动仍为用户手动维护。
- 公开排期强制中文正式名称与逐项中文来源证据，拒绝纯英文标题和无中文来源的 AI 翻译；插件采用中文官方源优先、限定检索次数和 90 秒软超时的快路径。
