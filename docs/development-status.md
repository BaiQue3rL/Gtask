# Gtask 1.0 开发状态

## 已完成

- Windows Electron + Vue 3 + TypeScript + SQLite 桌面应用。
- 原神、崩坏：星穹铁道、绝区零、鸣潮的任务、限时活动、周期事项、地图探索和自定义清单。
- 公开数据与官方个人数据两套互斥清单来源；不自动跨源融合。
- 米游社与库街区应用内登录、本地加密凭据、人工验证及手动同步。
- 个人数据完整快照、稳定官方 ID 绑定、异常批次 Codex 复审和元数据补全。
- Codex MCP 插件、固定六槽后台 Worker、可配置模型与推理强度、结构化同步进度和可靠取消。
- 两级地图基准目录、周期模式基准表、周常与任务重置、手动事项回收站、备份及拖动版块布局。
- 非阻塞软件更新检查，支持启动后检查、手动检查和后续扩展更新源。
- 正式 NSIS 安装器、自定义安装目录、桌面快捷方式、真实安装百分比和滚动详情。

## 发布边界

- 1.0 使用一份首发数据库基线，不携带封闭测试期逐版本迁移链。
- 正式包不包含 OCR、临时探测工具、测试数据库、登录凭据或开发缓存。
- 用户界面只展示固定产品语义；适配器和 Codex 的内部诊断信息不直接显示。
