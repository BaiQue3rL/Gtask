# 开发状态

更新时间：2026-07-20 10:07（Asia/Shanghai）

## 已完成

- Electron + Vue 3 + TypeScript + SQLite 工程骨架与 Windows 单实例窗口。
- 固定支持原神、崩坏：星穹铁道、绝区零、鸣潮；主线/支线仅记录完成状态。
- 手动事项新增、编辑、完成切换、软删除、按游戏回收站与单条恢复。
- 任务、活动、周期事项、地图探索、自定义清单均有只作用于当前版块的“删除已完成”。
- 限时活动开始/结束时间和实时倒计时。
- 周常周期键、Asia/Shanghai 时区、可选周重置日，以及运行中跨周自动重置。
- 深渊/挑战模式的模式标识、周期键、开始/结束时间；进入新周期时清除上一周期完成状态。
- 地图探索上级区域和 0～100% 探索进度。
- 每游戏独立的手动/自动模式，以及“公开排期”或“公开排期 + 米游社/库街区”同步范围。
- 启动自动同步协调器、同游戏防重复请求、来源级成功/失败/需要验证状态。
- 事务化远端合并：不删除手动项目、不恢复已归档项目、不覆盖本周期手动完成锁、批次失败整批回滚。
- 公共排期与个人数据按规范远端标识合并；适配器数据有运行时校验。
- 上次成功时间、失败/过期/需要验证状态持久化；成功数据超过 24 小时标记过期但不删除。
- Electron `safeStorage`/Windows DPAPI 凭据保险箱底座，以及设置页状态与一键清除入口。
- 每日 SQLite 在线一致性备份、升级前强制备份、设置页立即手动备份与最近备份列表；临时备份通过 `PRAGMA quick_check` 后才原子生效。
- 桌面端、CLI 和 MCP 都在数据库升级前强制创建旧版本一致性备份；v6 已保存同步来源 URL。
- 本地 JSON 命令服务、CLI 与正式 stdio MCP server；提供清单读写、恢复和版块清理等细粒度工具，支持批量事务写入和中文无损入口，外部进程写入后桌面端约 2 秒内自动刷新。
- 公开排期文档契约和安全 HTTP loader（HTTPS、逐跳域名白名单、超时、时效、内容类型及流式大小限制）。
- 绝区零式舆防卫战/危局强袭战个人数据解析器和适配器骨架。
- Windows 解包构建和真实窗口冒烟测试。
- 类型检查与 62 项自动化测试；构建后的 CLI/MCP 子进程均已完成真实调用测试。

5. 更完整的可访问性和小窗口响应式测试。

## 已知非阻塞项

- 当前使用 Electron/Node 内置 `node:sqlite`，Node 24 会输出实验性 API 警告；应用运行不受影响，稳定发布前需再次评估驱动选择。
- 应用图标暂时使用 Electron 默认图标。
- 原神和星铁个人战绩此前实测仍可能遇到 Geetest；同步协调器已经能区分“需要验证”和普通失败。
